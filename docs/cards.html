Card Catalog

Every card in the pick-3 pool, rendered live from src/game/cards.js — this page is the design catalog and the feature tracker in one. Add an entry to the file (implemented off), and it shows up here as a request; when the effect lands in game code the flag flips. The pacing model in the progression bench reads the same file's model fields.

Combat score = round(10 × damage × fire rate + 0.5 × HP + future terms), where fire rate is 1 / cooldown. Building kits multiply unit score by charges; one-shot buildings use one activation as their rate unit. Range, targeting, status effects, and enemies hit deliberately remain explicit future terms rather than hidden guesses.

Statuses: implemented = the effect exists in code (maybe test-only) · in pool = the draft can deal it. Refs are validated by scripts/validate.mjs — a card can never point at a building, tower, or upgrade that doesn't exist.
