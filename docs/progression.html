Progression Timeline

The whole run on one time axis, built around the pick-3 draft loop: feeding the thing earns XP, XP fills an exponential level curve, every level deals a draft, drafted buffs compound income, faster income feeds more. Game constants are imported live from src/game/data.js; card effects from src/game/cards.js (browse the catalog); intent from docs/progression-spec.js. Edit any of them, refresh, the charts move.
