hold-to-fill: the bar must complete before anything lands, and releasing early banks nothing. yield and damage apply to your own swings only — worker gathering still drops one per hit.

placement & text

overlay marks are screen-space, so without scaling they swamp the world zoomed out and disappear zoomed in. min/max clamp how far they track the camera.

action badge

presentation only — the badge previews what a held left click would hit and doubles as its fill bar, but these never touch targeting or swing timing. size carries the silhouette with it, drop slides the badge down from the target's ground point, and it rides the same zoom scaling as the bars above.

ground selectors

presentation only — corners mark the target or footprint, arcs mark the real gameplay radius, and nothing here moves either. pulse breathes the corners' offsets and the rings' opacity (never a ring's radius) off one clock, so every live mark stays in phase. thickness is world units like the mesh outlines under visibility, so a bracket keeps the same weight as the footprint it frames at any zoom. buildings with no gameplay radius draw no ring at all. follow is how much of the gap the cursor bracket closes each frame as it glides to whatever it is framing next — 1 is an instant snap, low values trail.

preview

debug aid, not a game feature — draws a sample mark on the camera's centre cell so states play never shows together (valid vs invalid, ring vs no ring) can be compared while tuning. it places nothing and changes no game value; sizes are the real footprints and the ring is the basic tower's real range. live marks keep drawing alongside it, so the sample is a fixed reference next to them.

economy

free costs bypasses the delivery pipeline: a placed blueprint and an accepted upgrade finish through the same completion calls a full delivery makes. It never edits an authored cost and never writes to the base store — the grant buttons are the only thing here that adds resources, and they add nothing else.

time

every phase button runs transitionPhase(), so wave setup, the next-night roll and the forecast reset happen exactly as they do when the clock runs out on its own.

combat

spawn picks a random edge. start wave forces night if it is day, then hands the chosen recipe to the live wave schedule with its first spawn due immediately. invulnerability is checked where the hit lands, so base hp never gets inflated.

population

instant workers skips the house spawn timer only; the two-per-house slot limit still applies. heal restores the base, every tower to its own variant's max, and every worker to full.

skills

temporary: the skill screen has no production trigger yet. it suppresses world input without pausing, cancels placement and closes the upgrade panel on the way in, and takes nothing away on the way out — esc or continue closes it.
